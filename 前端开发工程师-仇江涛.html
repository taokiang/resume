核心项目

信托业务中台管理系统（微前端架构升级 + AI 智能模块） 2023.10 – 2026.09
技术栈：Vue3 + TypeScript + Vite + Qiankun + pnpm Monorepo + Ant Design Vue + SSE + PDF.js

项目背景：原系统包含 8 个耦合业务模块，多团队并行开发时存在发布相互影响、公共能力重复建设及页面状态难保持等问题，同时需落地面向长文档的 AI 合同审核流程。

关键工作与难点：

  • 架构治理：主导 Qiankun + pnpm Monorepo 架构升级，划分主、子应用边界并统一通信约束、样式隔离和公共依赖管理，使业务子应用具备独立开发与发布能力。
  • AI 交互闭环：基于 SSE 实现 AI 对话增量流式 Markdown 渲染，通过缓冲区处理分片粘包，配合 requestAnimationFrame 做批量节流渲染提升体验；难点主要在于解决 Nginx 代理导致 SSE 长连接缓存超时、服务端数据分片粘包以及大量 token 高频 DOM 更新带来的页面卡顿问题。PDF原文引用联动 难点：AI 识别出的风险条目要能点击后精确定位到 PDF 原文并高亮，PDF 页数多时渲染卡顿。 做法：PDF.js 虚拟分页加载（只渲染可视区前后各 2 页）+ 文本层坐标映射 + 高亮锚点缓存；合同几百页时首开时间从秒级降到毫秒级。对话会话工程：中断、重生成与上下文管理 难点：用户中途停止生成、切换会话、重新生成时，流式请求的状态一致性。 做法：AbortController 中断 + 分片序号校验丢弃脏数据 + 会话级消息队列；长会话用虚拟滚动只渲染可视消息，上下文窗口裁剪策略（历史消息摘要化）。
  • 性能与状态：通过路由懒加载、资源预加载和骨架屏缩短关键加载路径；结合本地缓存与请求去重减少重复请求，保障页面状态在刷新后可恢复。
  • 公共能力建设：将企业定制化表单底层能力封装为独立 npm 私包，支持跨项目复用；实现大文件分片上传与断点续传，并基于 wangEditor 二次开发富文本编辑器。
  • 测试建设方案：计划借助 Codex 等 AI 编程工具生成与完善单元测试用例、梳理边界场景并分析测试失败；使用 Vitest 补齐 SSE 增量结果解析、审核状态转换及风险结果与 PDF 原文定位映射的测试，覆盖正常、空数据、异常数据和分析中断场景；结合 Vue Test Utils 验证关键组件交互，并计划接入 CI/CD 自动执行。

核心成果：完成 8 个核心业务模块的拆分与统一治理，实现子应用独立交付，并推动合同摘要、风险识别及反馈流程线上化。

维信金科金融仪表盘（实时监控大屏） 2021.03 – 2022.08
技术栈：Vue2 + Webpack + ECharts + Vuex + Axios + SSE + 响应式大屏适配

项目背景：管理层看板需持续呈现交易量、活跃度和风险指标，面对高频数据推送、多图表联动、历史数据累积及长时间运行等性能与稳定性挑战。

关键工作与难点：

  • 高频渲染：针对持续推送引发的重复渲染和卡顿，设计数据缓冲、节流与合并更新机制，结合 ECharts 增量渲染、采样和定向刷新控制主线程开销。
  • 大数据量渲染：针对历史数据累积至数十万点位的渲染卡顿，采用 appendData 增量加载与 large 大数据模式，结合 dataZoom 窗口抽样降采样，仅加载可视区间数据、滚动按需拉取，保障大数据量下的流畅交互。
  • 图表联动与下钻：构建中心化数据总线，实现指标卡、趋势图、分布图与明细表的多图表联动和数据下钻，结合 ECharts connect、brush 联动高亮，按需局部刷新避免全量重绘。
  • 连接稳定性：封装 SSE 长连接管理器，基于 EventSource 建立断线自动重连与消息序号校验机制，处理代理层连接超时与网络波动后的数据恢复，保障大屏长时间运行稳定。
  • 长时运行治理：针对大屏 7×24 小时不间断运行的内存泄漏问题，统一池化管理图表实例与定时器，页面不可见时暂停渲染并释放冗余实例，结合内存趋势监测设计定时自愈刷新机制。
  • 无人值守轮播：实现路由级轮播调度器，支持多页面自动轮播与全屏自动化，覆盖接口失败重试、空数据占位兜底等异常场景，满足挂墙展示下无人工干预持续可用。
  • 多屏适配：统一设计稿缩放基准，结合视口单位、媒体查询和图表 resize 协调，处理常用分辨率及极端宽高比下的布局与图表变形问题。

核心成果：交付面向管理层的实时监控看板，实现高频数据下的平稳刷新、网络异常恢复和多分辨率稳定呈现，支撑 7×24 小时无人值守稳定运行。

维信卡卡贷 App 混合 Web 开发（信用卡金融业务） 2018.10 – 2020.06
技术栈：Vue2 + Webpack + JSBridge + 离线包（增量更新） + vw 移动端适配 + RSA/AES 加密

项目背景：负责信用卡还款、贷款申请和账单查询等核心 H5 链路，需要统一 iOS/Android WebView 能力差异，并兼顾弱网加载、版本发布安全和金融数据保护。

关键工作与难点：

  • 跨端通信：主导基于回调 ID 的双向协议设计，以 Promise 封装、统一错误模型和版本兼容策略屏蔽平台差异，沉淀设备、相机及生物识别等 20+ 项 Native 能力。
  • JSBridge 安全加固：在双向协议基础上增加 JSAPI 分级鉴权（公开、登录态、高敏感三级）与调用域名白名单校验，结合调用频控和时间戳签名防重放，防止非授信页面滥用 Native 敏感能力。
  • 登录态与 Cookie 同步：解决 iOS/Android WebView Cookie 管理策略不一致导致的双端登录态不同步问题，统一票据下发并建立 H5 与 Native 双通道登录态同步机制，请求层拦截失效态自动拉起重登，保障核心交易链路会话连续。
  • 加载与容灾：推动增量离线包、版本校验、缓存失效和 CDN 异常回源机制落地，配合 WebView 预加载与骨架屏，在弱网和资源更新失败时保障核心流程可用。
  • 复杂交互治理：针对账单、交易流水等长列表数据渲染卡顿，引入虚拟滚动只渲染可视区节点；解决页面滚动穿透、H5 侧滑手势与页内横滑滑动冲突等交互问题，提升核心链路操作体验。
  • 移动端适配：基于 vw 实现不同屏幕尺寸下的布局适配，结合响应式样式处理图片、视频等多媒体内容的缩放与展示，解决不同设备及 iOS/Android WebView 的兼容性问题。
  • 金融场景治理：统一处理安全区域、键盘遮挡和页面生命周期问题，并配合 Native 落实敏感数据加密、页面禁缓存及安全键盘能力。

核心成果：完成核心金融 H5 模块及跨端基础能力建设，首屏加载时间显著降低；JSBridge 与离线包方案后续复用于公司其他金融 App。
